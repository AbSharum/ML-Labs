# Machine Learning Labs

Lab notebooks from a Machine Learning course.

## Contents

- `Lab 1/` — Introductory ML notebook.
- `Lab 2/` — KNN classifier trained on the iris dataset (`knn.pkl`).
- `Lab 3/` — A PyTorch neural network (`knn.ipynb`, `model.pth`) plus a market dataset.

## Stack

Python (Jupyter, scikit-learn, PyTorch).

## Running

```
pip install jupyter scikit-learn torch pandas
jupyter notebook
```

Then open any `.ipynb` file. Pretrained model artifacts (`.pkl`, `.pth`) are included so notebooks can load results without retraining.
